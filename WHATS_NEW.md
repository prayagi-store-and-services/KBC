## 1.1.43 - Cleaner update notices

- Update checks now happen at most every 6 hours instead of once a day, so new versions are noticed sooner.
- Settings no longer shows the long static update explainer; the update card appears only when a newer version is verified.

## 1.1.42
- Tablet and smart-class layout. On wide screens the app no longer stretches edge to edge: every screen stays centred in a comfortable reading column, and main headings and buttons are larger for distance viewing. Phone layouts are unchanged.
- Truth fix: the home screen showed a made-up "3 days active" streak. No streak is tracked anywhere, so the line now truthfully says every game brings fresh questions.

## 1.1.41
- No repeated questions. A served question's exact wording is never shown again, in any game. Earlier, a generator that had used up its small internal pool could silently serve an identical question again; every path now keeps drawing fresh variations until the wording is new. Seven generators that had only a single fixed question (age puzzles, grid rotation, cryptarithm, crime-alibi timelines, knights-and-knaves, syllogisms, minimax) now produce real varied questions with verified answers.
- Game start no longer asks for Camera or Microphone permission. The app never records or captures anything, so the demand was removed. The Notifications request is unchanged.
- Profile has five official Netra social profiles, the KBC website and a separate private complaint/feedback form. External browser links open only after a tap. No automatic follow, rating or post, new permission or background network request. Private feedback is sent through FormSubmit by the web form. No live delivery or physical-phone testing is claimed.
